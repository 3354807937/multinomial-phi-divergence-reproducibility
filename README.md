# Multinomial phi-divergence reproducibility

Code and aggregate data for pseudo-minimum phi-divergence estimation in multinomial logistic random-intercept models under complex sampling.

The repository contains the simulation programs, stored replicate-level results, numerical verification utilities, and four aggregate body mass index (BMI) cells used in the analysis.

- `Reproducibility/`: Python programs, input data, stored results, pinned dependencies, and [reproduction instructions](Reproducibility/README.md).
- `Manuscript_Source/generated/`: numerical table fragments regenerated by the audit.
- `Manuscript_Source/figures/`: the three vector figures regenerated by the audit.

Keep these two directories next to each other: `final_audit.py` writes tables and figures to the sibling `Manuscript_Source` directory.

The BMI file contains four age-by-gender aggregate cells, totaling 74,640 individuals. Individual health-examination records are not included.
